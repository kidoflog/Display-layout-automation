# ディスプレイ高さ調整アプリ 要件定義書

版：0.5  
作成日：2026-09-20／更新日：2026-10-05  
状態：主要要件確定・詳細ルールの一部は提案  
対象：macOS向けアプリの初版

本書は要件定義を目的とする。初期実装は進行中であり、検証状況は実装記録に記す。ユーザーが合意した内容を「確定」、要件を具体化するための追加案を「提案」、実装段階で確認する事項を「要検証」と区別する。

## 1. 目的と成功条件〔確定〕

ユーザーが指定した高さで、画面間を移動するカーソルの段差をなくす。

ユーザーは、左右に隣接する基準画面と対象画面のそれぞれで、押下して表示される線をドラッグで合わせ、離して高さを確定する。アプリは、その2点がmacOSの配置座標上で同じY座標になるよう、対象画面の上下位置を調整する。

保証対象は、測定した各組の指定位置である。画面間で実物上の表示の大きさが異なる場合、すべての高さでカーソルの段差がなくなることは保証しない。

## 2. 初版の対象範囲〔確定〕

| 項目 | 初版の要件 |
|---|---|
| OS | macOS。対応する最低バージョンは未決定 |
| 台数 | 2枚および3枚以上。実機3枚で検証する |
| 表示方式 | 拡張ディスプレイ |
| 調整方向 | Y方向のみ |
| 固定するもの | 主ディスプレイ、各画面のX座標、左右関係 |
| 測定方法 | 透明オーバーレイ上で、基準画面→対象画面の順に、それぞれ押下・ドラッグ・リリース |
| 表示補助 | 選択した位置に見やすいマーカーを表示 |
| 適用方法 | 全組の点指定結果を収集し、最後に全体をまとめて仮適用 |
| 保存 | 確定した配置をmacOSへ永続保存し、アプリにも保存 |
| 復元 | アプリ起動中、条件が一致する再接続時に自動仮適用 |
| 自動起動 | ログイン時の自動起動を設定できる |

ミラーリング、Sidecar、AirPlay、仮想ディスプレイは対象外。解像度・表示倍率・回転を変更する機能、X方向の調整、縦積みへの配置変更は初版に含めない。既に設定されている回転角度などは変更せず、保存・照合する。

## 3. 用語と調整順序

### 3.1 用語〔確定〕

- **主ディスプレイ**：操作開始時にmacOSで主画面となっているディスプレイ。全体の基準として固定する。
- **基準画面**：各組の1点目を押下・ドラッグ・リリースで選ぶ画面。最初は主ディスプレイ、以後は測定済みの画面も使用する。
- **対象画面**：各組の2点目を押下・ドラッグ・リリースで選ぶ、未測定の画面。
- **隣接**：操作開始時のmacOSの配置において、左右の辺が正の長さにわたって接していること。角だけの接触、上下の接触は含めない。
- **測定済み**：基準との対応点が取得でき、調整後の予定位置を計算できる状態。まだ実際の配置は変更していない。
- **直前の配置**：手動操作開始時、または再接続が安定した後の自動仮適用直前の配置。ケーブルを抜く前の配置とは区別する。

### 3.2 基本ルール〔確定〕

主ディスプレイから始め、測定済みの隣接画面を基準に、未測定の画面を順に合わせる。各対象画面は1回ずつ測定する。各組で基準点を指定し直す。

| 操作開始時の配置 | 測定する組み合わせ |
|---|---|
| 主・B・C | 主→B、その後B→C |
| B・主・C | 主→B、および主→C |
| 主・B・C・D | 主→B、その後B→C、その後C→D |

主を含むN枚すべてをこの方法で調整できる場合、N−1組、合計2×(N−1)点の指定となる。完了後に再調整するときは、最初から測定し直す。

### 3.3 順序の詳細〔提案〕

アプリが次に測定する組を案内する。主ディスプレイに直接隣接する画面を優先し、そこから外側へ順に進める。同じ優先順位の候補が複数ある場合の並び順は、画面識別子などで固定する。

隣接関係は操作開始時に確定し、点の選択中には変更しない。主から左右の隣接関係をたどって到達できない画面がある場合、初版では操作全体を開始せず、対象外の配置であることを案内する。

複数の経路で同じ画面に到達できる場合は、基準となる経路を1つ選ぶ。選択しなかった組について、指定高さの一致は保証しない。

## 4. 手動調整の操作フロー〔確定〕

1. ユーザーが調整を開始する。
2. ディスプレイ構成と直前の配置を取得する。
3. 各画面に透明オーバーレイを表示し、今回の基準画面と対象画面を案内する。
4. ユーザーが基準画面でマウスボタンを押すと、候補の線を表示する。ボタンを押したまま上下にドラッグすると線が追従し、基準画面内で離すとその高さを確定してマーカーを表示する。
5. ユーザーが対象画面でも同じ操作を行う。対象画面内で離すとその高さを確定してマーカーを表示し、調整後の予定位置を計算する。どちらの画面でも押下とリリースが同じ位置なら、その位置を指定する。画面外で離した場合は確定せず、同じ点を再操作できる。
6. 未測定画面があれば、次の組について手順3〜5を繰り返す。この間、実際のディスプレイ配置は変更しない。
7. 全組の測定が完了したら、全体の配置をまとめて仮適用する。
8. 仮適用が完了し、主画面に確認画面を表示した時点から10秒を数える。
9. ユーザーが確定すると、配置を永続保存する。Escまたは時間切れなら直前の配置へ戻す。

点の選択中には10秒の期限を設けない。確認画面には「確定」と残り時間を表示し、ユーザーがカーソルの画面間移動を試せる状態にする。

### 4.1 入力の詳細〔提案〕

- 案内された画面以外の操作は点指定として受理せず、正しい画面を案内する。
- 同じ画面で2点を指定しても測定完了にはしない。
- どちらの画面でもドラッグしている間は候補線だけを更新し、実際のディスプレイ配置を変更しない。リリース後に次の点へ進む。
- オーバーレイ上の点指定で、その背後にある他アプリを操作しない。
- マーカーは明暗の異なる背景でも見分けられ、どちらが基準点か分かる表示にする。
- 点の選択中のEscは操作全体を終了する。配置変更はまだ行っていないため、変更前の状態を維持する。
- 確定後は測定状態を破棄し、次回は新しい操作として開始する。

## 5. 座標と適用条件

### 5.1 計算上の要件〔確定内容の具体化〕

点は「どの画面で選んだか」と「その画面内の位置」を組み合わせて扱う。表示倍率の異なる画面でも比較できるよう、macOSの配置座標と整合する単位に統一する。

上から下へ増えるY座標で、対象画面の予定位置は次の関係を満たす。

```text
対象画面の予定上端Y
  = 基準画面の予定上端Y
  + 基準画面内で選んだ点のY
  − 対象画面内で選んだ点のY
```

連鎖する場合は、基準画面の「調整後の予定位置」を使用する。例えば主→B→Cの順なら、Cの計算にはBの調整前の位置ではなく、Bの予定位置を使う。

主ディスプレイの位置は固定し、他の画面のX座標も操作開始時の値を維持する。解像度・表示倍率・回転は変更しない。

### 5.2 適用結果の扱い〔提案〕

全体の予定配置について、重なりがないこと、測定した組の左右の接触が維持されること、主画面から各対象画面へ移動できることを確認してから仮適用する。

macOSは要求位置を調整する場合があるため、成功応答だけで判断せず、仮適用後の実際の配置を確認する。主画面固定・X座標固定・選択点の高さ一致などを満たせない場合は成功扱いにせず、直前の配置へ戻して理由を案内する。

数値上の高さ一致の許容差は、各組につきmacOSの配置座標の1単位以内を暫定基準とする。端数処理を含む最終値は実機検証で確定する。物理パネルの1画素とは区別する。
仮適用後と確定後の各画面の上端Y座標は、整数に丸めた予定位置との完全一致を求める。指定点同士の高さ差には、丸めを含めて前記の1単位以内を適用する。

## 6. 確定、保存、キャンセル

### 6.1 状態ごとの動作〔確定〕

| 状態・操作 | 動作 |
|---|---|
| 測定中にEsc | 操作全体を終了。配置を変更しない |
| 仮適用後に確定 | macOSへ永続保存し、アプリの保存配置を更新 |
| 確認中にEsc | 直前の配置へ戻す。保存配置を更新しない |
| 確認画面表示から10秒以内に確定されない | 直前の配置へ戻す。保存配置を更新しない |
| 確認中にアプリを終了 | 仮適用前の配置へ戻す |
| 確定後にアプリを終了 | 確定した配置を維持 |

変更前の配置を操作中のメモリに保持する。仮適用と永続保存を区別し、ユーザーが確定する前に、新しい配置を次回の自動復元対象として保存しない。

### 6.2 保存内容〔確定内容の具体化〕

- macOSから取得したディスプレイの識別子。
- ディスプレイの組み合わせと、主ディスプレイの識別子。
- 各ディスプレイの確定した配置。
- 各ディスプレイの解像度、表示倍率、回転。

アプリの設定ファイルには確定済みの配置と保存日時だけを記録する。未確定の配置はmacOSの一時的な適用方法で扱い、アプリ終了時の復帰をmacOSに任せる。変更前の配置は操作中のメモリにだけ保持し、設定ファイルには残さない。強制終了後の復帰は実機で要検証とする。

保存はアプリ自身の設定領域とmacOSの提供する仕組みを利用する。macOSの内部設定ファイルを直接書き換えることを前提としない。

### 6.3 保存単位〔提案〕

初版は、識別子・主画面・表示設定で区別される構成ごとに、最新の確定配置を1件保存する。同じ機器・同じ表示設定で机上の位置だけを変えた場合は、手動で再調整して更新する。名前付きの複数プロファイル切替は別途検討する。

## 7. 再接続時の自動復元

### 7.1 復元条件とフロー〔確定〕

アプリ起動中に再接続を検知し、接続構成が安定した後に保存内容と照合する。次の条件がすべて一致し、各画面を一意に識別できる場合に自動復元する。

1. ディスプレイの組み合わせ。
2. 主ディスプレイ。
3. 各ディスプレイの解像度・表示倍率・回転。

条件が一致しない場合や識別が曖昧な場合は、自動復元を行わず手動調整へ誘導する。

条件が一致した場合は、自動復元直前の配置をメモリに保持し、保存済み配置を仮適用する。適用完了と確認画面表示から10秒以内の確定を求める。Escまたは時間切れの場合は自動復元直前の配置へ戻す。キャンセル後、同じ接続状態のまま自動復元を繰り返さない。

ログイン時の自動起動を設定できるようにする。アプリはメニューバーに常駐し、操作ウィンドウを閉じても再接続を監視する。メニューバーから操作ウィンドウの再表示と終了ができる。ログインによる起動時には操作ウィンドウを前面に出さず、手動起動時には表示する。自動復元の確認が必要なときは起動方法によらず表示する。アプリが動作していない間はアプリ独自の復元処理を行わない。確定済み配置のmacOS側での保持とは区別する。

### 7.2 自動復元の詳細〔提案・確認対象〕

- **再接続でX座標が変わっている場合**：X座標固定を自動復元にも適用し、保存時とX座標が異なる場合は自動復元を見送る。この条件は7.1の一致条件への追加案であり、未確定とする。
- **既に保存配置と一致している場合**：配置を再適用せず、10秒の確認も表示しない。
- **アプリ起動時**：接続済みの構成に対しても、同じ条件で一度照合する。
- **外部からの手動変更**：確定後にユーザーがシステム設定で配置を変更しても、その場で強制的に戻さない。次の接続イベントまたは明示的な手動操作まで再適用しない。
- **自動起動の初期値**：自動起動を有効にするかはユーザーが選べるようにする。初期値は画面設計時に決定する。

## 8. 中断と異常時の要件〔提案〕

| 発生事象 | 動作 |
|---|---|
| 測定中に接続・切断・主画面・表示設定が変わる | 測定を中断し、古い座標を適用しない |
| 確認中に構成が変わる | 仮適用を中断。現在の構成で復元可能な範囲を戻し、保存配置は更新しない |
| 配置の適用に失敗する | 復元を試み、適用失敗を案内する |
| 復元にも失敗する | 復元できたと表示せず、現在の状態と手動対応が必要なことを案内する |
| 確認中にスリープ・ログアウトする | 未確定の変更を確定扱いにせず、中断・復元する |
| 対象外の画面や判別不能な画面が接続されている | 初版では操作全体を見送り、理由を案内する |

強制終了などで通常の終了処理が動かない場合に、未確定の配置を永続化せず元の配置へ戻せるかは要検証。復旧手段の詳細は技術設計で決める。

## 9. オーバーレイと権限

〔確定〕点の取得はアプリの透明オーバーレイ上で行い、できるだけシンプルな構成にする。

〔提案〕画面の内容を画像として取得せず、点・画面識別子・表示設定をローカルで扱う設計とする。画面収録や他アプリの入力監視を前提にしない。

〔要検証〕対象macOSで必要になる権限、全画面表示中のオーバーレイとEscの動作、主画面上の確認ボタンを確実に操作できること。追加権限が必要と判明した場合は、その理由とユーザーへの影響を要件へ反映する。

## 10. 実機3枚での受け入れテスト

以下は受け入れテスト計画であり、動作確認結果ではない。表示モード等の数値を確認するテストと、実際のカーソル移動を目視するテストを組み合わせる。

| ID | テスト | 合格条件 |
|---|---|---|
| AT-01 | 主・B・Cの連鎖配置 | 主→B、B→Cを測定でき、各組の指定点のY座標が一致する。CはBの調整後の予定位置を基準に計算される |
| AT-02 | B・主・Cの配置 | 主をそれぞれの基準としてBとCを調整できる |
| AT-03 | 測定中の配置 | 全組の測定が終わるまで、実際の配置が変わらない |
| AT-04 | 変更範囲 | 仮適用・確定後とも主画面の位置、全画面のX座標、解像度・表示倍率・回転が維持される |
| AT-05 | 異なる表示倍率 | 混在する表示倍率を正しく扱い、指定点の高さ一致を満たす。すべての物理的な高さの一致は判定対象としない |
| AT-06 | 2枚での操作 | 1組の点指定で仮適用・確定まで完了できる |
| AT-07 | 測定中のEsc | オーバーレイが閉じ、操作開始前の配置が維持される |
| AT-08 | 確認中のEsc／10秒経過 | 全体が仮適用直前の配置へ戻り、保存済み配置が上書きされない |
| AT-09 | 確定後の終了・再ログイン | 同じ構成で確定配置が維持され、アプリ終了を理由に元へ戻らない |
| AT-10 | 同じ構成の再接続 | 構成が安定した後に自動仮適用され、確認画面表示から10秒間の確定機会がある |
| AT-11 | 自動復元のキャンセル | 復元直前へ戻り、同じ接続状態で再適用・再確認を繰り返さない |
| AT-12 | 構成・主画面・表示設定の不一致 | 保存配置を自動適用せず、手動調整へ誘導する |
| AT-13 | 測定中・確認中の切断 | 古い構成を確定保存しない。復元の結果を正しく案内する |
| AT-14 | 同型モニター・ポート／ドック変更 | 識別が一意な場合のみ正しく対応付ける。曖昧な場合は自動適用しない |
| AT-15 | 実現できない配置・OSによる位置補正 | 主画面やX座標などの条件違反を検出し、成功扱いにせず復元する |
| AT-16 | 誤った画面へのクリック | 誤入力で測定を進めず、正しい画面を案内する |
| AT-17 | カーソル移動の目視 | 各測定組の指定した位置付近で、意図した高さへカーソルが移動する |
| AT-18 | 対象点のドラッグ操作 | 押下時に候補線を表示し、ドラッグ中は追従する。画面内で離した高さで確定し、画面外で離した場合は確定せず再操作できる |
| AT-19 | 基準点のドラッグ操作 | 押下時に候補線を表示し、ドラッグ中は追従する。押下だけでは対象点へ進まず、画面内で離した高さで確定する。画面外で離した場合は確定せず再操作できる |

AT-01〜19のうち提案事項に依存する判定は、該当要件を確定した時点で更新する。数値許容差は5.2の暫定基準を使用する。

実機検証時には、Mac機種・CPU、macOSバージョン、3枚のモニター情報、主画面、接続ポート／ドック、解像度・表示倍率・回転、開始時の配置を記録する。

## 11. 残る決定事項

主要機能の範囲は確定している。以下は実装着手前に確定、または検証計画へ反映する。

1. 再接続時にX座標が保存時と違う場合、自動復元を見送るという7.2の追加案。
2. 対応するmacOSの最低バージョンと、Apple Silicon／Intelの対象範囲。
3. 複数の隣接候補がある場合の固定順序、到達できない画面や対象外画面を含む場合の扱い。
4. 保存単位、既に一致する場合の確認省略、起動時の照合、自動起動の初期値。
5. 強制終了・構成変更・権限制約への対応と、数値上の一致の許容差。

## 12. 技術的根拠

要件の成立条件を確認するための資料。特定の実装方法を本書で確定するものではない。

- [Apple：ディスプレイ配置の変更](https://developer.apple.com/documentation/coregraphics/cgconfiguredisplayorigin%28_%3A_%3A_%3A_%3A%29) — 隙間や重なりを避けるため、要求した位置が調整される場合がある。
- [Apple：配置の一括適用](https://developer.apple.com/documentation/coregraphics/cgcompletedisplayconfiguration%28_%3A_%3A%29) — 複数の変更を単一のトランザクションとして適用する。
- [Apple：配置の永続保存](https://developer.apple.com/documentation/coregraphics/cgconfigureoption/permanently) — 同じユーザーの将来のログインセッションにも保存する仕組みがある。
